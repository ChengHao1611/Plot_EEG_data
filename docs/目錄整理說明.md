## 共通資料格式與命名

### EEG EDF

`data/raw_edf/eeg/` 的一般 EEG 檔案供 α 波、眼動與 Status 事件流程使用。抽查的 EDF 含下列 9 個通道，取樣率為 500 Hz：

```text
FP1, FP2, C3, CZ, C4, O1, OZ, O2, Status
```

`data/raw_edf/auxiliary/s01_060926_1n_car_position.EDF` 含下列 7 個通道，供車道偏移分析使用：

```text
FP1, FP2, O1, OZ, O2, vehicle position, Status
```

### DAT

所有 DAT 都以逗號分隔，第一個數字是筆數，後續數字是秒數：

```text
3,15,48,120
```

### 駕駛狀態事件 Excel

`eeg_analysis/driving_state/predict_algorithm.py` 至少需要英文欄位：

```text
second, react_time
```

現有的 `data/derived/feature_tables/s09_060313n_raw_status_and_30s_eyeblink.xlsx` 欄位為：

```text
second, eyeblinking_count, react_time, sleep
```

## 自動 α 波與眼動偵測

### `eeg_analysis/detection/detect_alpha_and_eyeblink.py`

此為自動偵測的命令列入口。它從 EDF 找出 FP1、FP2，使用 FP2 進行眼動與 α 波偵測。

| 項目 | 說明 |
| --- | --- |
| 必填輸入 | `--file <EEG EDF 路徑>`；未提供時會互動詢問。 |
| 指令 | `python -m eeg_analysis.detection.detect_alpha_and_eyeblink --file data/raw_edf/eeg/s01_061102n_raw.EDF` |
| 輸出 | 在輸入 EDF 同資料夾寫入 `Alpha.dat` 與 `eyeblink.dat`。 |
| DAT 內容 | 第一個數字為筆數；後續為偵測到的秒數。 |

### `eeg_analysis/detection/record_alpha.py`

Alpha偵測使用1 Hz高通、30 Hz低通與逐秒FFT，分別累加Theta（4–7 Hz）、Alpha（8–12 Hz）及Beta（13–20 Hz）的 `Amplitude²`。程式會依實際取樣率與FFT長度，動態選擇最接近頻帶上下限的FFT bin；例如500 Hz、512點FFT時，Alpha使用索引8～12，即7.8125～11.71875 Hz。眼動秒不進行FFT；其餘秒數只有在 `Alpha > Theta` 且 `Alpha > Beta` 時才寫入DAT。此模組可由整合流程呼叫，也可獨立從命令列執行。

| 項目 | 說明 |
| --- | --- |
| 函式輸入 | EDF路徑、輸出DAT路徑、可選通道名稱、眼動秒數與分析秒數範圍。 |
| 指令 | `python -m eeg_analysis.detection.record_alpha --file <EDF> --eye-dat <眼動DAT> --end-second 300` |
| 輸出 | 符合Alpha條件的秒數DAT，函式另回傳逐秒Theta／Alpha／Beta Power。 |
| DAT內容 | 第一個數字為符合條件的秒數量，後續為向上取整後的一基秒數。 |

### `eeg_analysis/detection/record_arousal.py`

眼動尖峰偵測的函式庫，由自動偵測主程式呼叫，沒有獨立命令列介面。

| 項目 | 說明 |
| --- | --- |
| 函式輸入 | MNE Raw 物件、FP1／FP2 通道、輸出 DAT 路徑。 |
| 輸出 | 指定路徑的眼動秒數 DAT。 |
| 主要預設 | 動態高度閾值為 `median + 0.5 × MAD`，prominence 門檻為 `0.00007`。 |

## 疲勞駕駛預測系統：功能一

### `eeg_analysis/fatigue_driving_prediction_system/function_one.py`

此命令讀取單一EDF，以Status 251／252作為偏移開始、253作為導正開始，將事件時間向上取整，並將Reaction Time以一般四捨五入記錄至小數點第一位後檢查第1～300秒。出現第一個 `Reaction Time >= 1.6` 秒事件後，程式從下一個反應事件起算60秒；若窗口內又出現一個疲勞事件，輸出疲勞並停止，否則呼叫 `record_arousal.py` 與新版 `record_alpha.py` 建立RT及Alpha Power平均／中位數baseline。

```powershell
python -m eeg_analysis.fatigue_driving_prediction_system.function_one --file data/raw_edf/eeg/s11_060920_1n_raw.edf
```

預設輸出至 `data/derived/fatigue_driving_prediction_system/<record_id>/`，包含 `reaction_time_events.xlsx`、`function_one_results.xlsx` 與 `rt_validation.png`；非疲勞資料另有 `eyeblink.dat` 及 `Alpha.dat`。

## α 波人工標註驗證

### `eeg_analysis/alpha_validation/alpha_validation.py`

此程式把 EDF 的自動 α 波判定與人工 α DAT 比較，輸出 true／false／miss 的逐秒時域與頻域圖。

| 項目 | 說明 |
| --- | --- |
| 必填輸入 | 位置參數 `<資料夾或 raw EDF 路徑>`。資料夾模式下必須只含一個 `*_raw.EDF`。 |
| 必要旁檔 | 與 EDF 同資料夾的 `<record_id>_alpha.dat`；`record_id` 會移除 EDF 檔名尾端的 `_raw`。 |
| 可選眼動 DAT | `<record_id>_raw_arousal info.dat` 或 `<record_id>_arousal info.dat`；其秒數會從 α 偵測結果排除。 |
| 常用參數 | `--channel FP2`、`--alpha-threshold 1000`、`--plot-dir <資料夾>`、`--normal-dist-output <PNG>`、`--highpass`、`--lowpass`、`--nfft-pow2`、`--max-plot-freq 100`。 |
| 頻帶參數 | `--alpha-low 7.8`、`--alpha-high 12.5`、`--peak-low 1.9`、`--peak-high 30`；也接受 theta／beta 參數，但目前運算沒有使用 theta／beta 值。 |
| 指令 | `python -m eeg_analysis.alpha_validation.alpha_validation data/raw_edf/eeg/s01_061102n_raw.EDF` |
| 預設輸出資料夾 | `<record_id>_alpha_detection_plots/`，位於 EDF 同資料夾。 |
| 輸出檔案 | `true/s00001_true.png`、`false/...png`、`miss/...png`，以及 `<record_id>_alpha_energy_normal_distribution.png`。 |

注意：`--notch-freq` 雖可傳入，但目前套用 notch 的程式碼被註解，不會生效。

### `alpha_detection_paths.py`、`alpha_detection_plotting.py`、`alpha_detection_distribution.py`

這三個檔案是 `alpha_validation.py` 的輔助模組，沒有獨立命令列介面。

| 檔案 | 用途 | 輸出 |
| --- | --- | --- |
| `alpha_detection_paths.py` | 尋找 EDF、人工 α DAT、可選人工眼動 DAT，並建立預設圖檔位置。 | 無直接輸出。 |
| `alpha_detection_plotting.py` | 產生 true／false／miss 的逐秒時域與頻域圖。 | PNG。 |
| `alpha_detection_distribution.py` | 將 true+miss 與 false 的 α 能量畫成直方圖與常態擬合。 | PNG。 |

## 眼動驗證與分布

### `eeg_analysis/eye_movement/eye_movement_validation.py`

從 EDF 自動偵測眼動，並與人工 DAT 比較 true／false／miss。

| 項目 | 說明 |
| --- | --- |
| 必填輸入 | `--file <EDF 路徑>`；未提供時會互動詢問。EDF 必須含 FP1、FP2。 |

| 偵測參數 | `--height-mad-scale 0.5`、`--prominence 0.00006`、`--l-freq 0.1`、`--h-freq 10`、`--no-filter`。 |
| 繪圖參數 | `--distribution` 會產生振幅分布圖；`--plot-window-sec` 目前不生效，因為逐事件繪圖程式碼被註解。 |

### `eeg_analysis/statistics_30s_alpha_eyeblink_of_fatigue/plot_fatigue_segment_pre30_distributions.py`

讀取多份上述中文欄位 Excel，以疲勞區段為單位彙整區段開始前 30 秒的 α 與眼動分布。疲勞區段從第一個 `反應時間 >= 1.6` 的 event 開始。第一個 `反應時間 < 1.6` 的 event 為恢復開始；接續 60 秒內任一反應時間 event 若為 `>= 1.6`，便重新開始恢復計時。程式確認恢復已持續 60 秒後，將區段結束秒數記為「恢復開始秒數 + 60」。

| 項目 | 說明 |
| --- | --- |
| 輸入 | `--input-dir <含上述 XLSX 的資料夾>`；預設為程式同層 `data/`。 |
| 輸出位置 | `--output-dir <資料夾>`；預設為 `data/fatigue_segment_pre30_output/`。 |
| 開始門檻 | `--start-threshold 1.6`；反應時間大於等於此值時開始區段。 |
| 恢復條件 | `--recovery-threshold 1.6`、`--recovery-duration-seconds 60`；恢復期間的所有反應時間 event 必須嚴格小於 1.6 秒，並持續 60 秒。等於 1.6 秒會中斷恢復並重新計時。 |
| Window 長度 | `--window-seconds 30`；固定收集區段開始秒數 `-29` 至 `0`，共 30 秒，並包含開始秒。 |
| Excel 輸出 | `fatigue_segment_pre30_summary.xlsx`；包含「疲勞區段明細、前30秒逐區段、前30秒統計、檔案統計、說明」。區段明細會記錄恢復開始 event 與「恢復開始 + 持續秒數」的結束秒數。 |
| 圖檔輸出 | `fatigue_segment_pre30_eye_distribution.png`、`fatigue_segment_pre30_alpha_distribution.png`；均為 min–max 箱型圖。箱體的 Q1／中位數／Q3 採 nearest-rank（不插值），必定是原始觀測值；鬚為實際最小值與最大值。 |
| 指令 | `python -m eeg_analysis.statistics_30s_alpha_eyeblink_of_fatigue.plot_fatigue_segment_pre30_distributions` |

## 實驗與原型

### `tools/experiments/check.py`

人工與自動眼動 DAT 的簡易比對工具。輸入檔案路徑目前寫死為其他資料夾，沒有命令列參數；執行後會在目前目錄輸出 `comparison_details.txt`。適合作為程式碼參考，不建議直接用於目前資料夾。

### `tools/experiments/GetAlpha.java`

Java／Android 用的 α 波 FFT 原型。以 `detectAlpha(double[] data, int fs)` 接收資料與取樣率，回傳每秒 α 判定 `alphaMatrix` 及每 30 秒移動量 `movement`。它不讀寫檔案，且需 JDSP (`FastFourier`) 函式庫；目前沒有建置設定。
