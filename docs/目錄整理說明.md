整理日期：2026-07-24。檔案已依資料、分析流程、GUI 與實驗工具完成分類；所有原始碼、資料、既有輸出與快取檔都已保留。

## 資料流程

```text
data/raw_edf/eeg/*.EDF
  ├─> feature_extraction/record_status_and_30s_eyeblink.py
  │     └─> data/derived/feature_tables/*_status_and_30s_eyeblink.xlsx
  │           └─> feature_extraction/plot.py
  │
  ├─> detection/record_alpha.py + record_arousal.py
  │     └─> Alpha.dat、eyeblink.dat（目前仍輸出到所選 EDF 的同目錄）
  │           └─> driving_state/predict_algorithm.py
  │                 （另需含 second/react_time 的事件 Excel）
  │                 └─> data/derived/driving_state/駕駛狀態分析結果.xlsx
  │
  ├─> eye_movement/eye_movement_validation.py
  │     └─> 自動眼動 DAT、event_summary.csv、評估報告與診斷圖
  │           └─> eye_movement_distribution.py（可直接或獨立重繪分布圖）
  │
  ├─> alpha_validation/alpha_validation.py
  │     └─> true / false / miss 圖檔與 α 能量分布圖
  │         （另需人工標註的 *_alpha.dat）
  │
  └─> legacy_chinese_gui/record_status_and_eyeblink_to_xlsx.py
        └─> 中文欄位 Excel ──> legacy_chinese_gui/main.py
```

## 程式檔案與關係

### `eeg_analysis/feature_extraction/`

| 檔案 | 功能 |
| --- | --- |
| `record_status_and_30s_eyeblink.py` | 命令列主程式。逐秒輸出眨眼計數、Status 反應時間與保留空白的 sleep 欄位。預設輸出至 `data/derived/feature_tables/`，也可用 `--output` 指定位置。 |
| `plot.py` | 讀取上述英文特徵表的 GUI；繪製 α/β、α/θ 或 α/total、眨眼與事件區段。 |

### `eeg_analysis/alpha_validation/` 與 `eeg_analysis/common/filters/`

| 檔案 | 功能 |
| --- | --- |
| `alpha_validation.py` | α 波驗證主程式。需要一個原始 EDF 與同資料夾的人工 `*_alpha.dat`；比對結果為 true／false／miss。 |
| `alpha_detection_paths.py` | 尋找原始 EDF、人工 α／眼動 DAT 與預設圖檔資料夾。 |
| `alpha_detection_plotting.py` | 為 true／false／miss 秒數輸出時域與頻域 PNG。 |
| `alpha_detection_distribution.py` | 將驗證結果的 α 能量畫為直方圖與常態擬合 PNG。 |
| `common/filters/eeg_filters.py` | 高通、低通與 notch 濾波器；被 α 偵測與驗證流程共用。 |
| `common/filters/__init__.py` | 提供 `from eeg_analysis.common.filters import ...` 的匯出入口。 |

### `eeg_analysis/detection/`

| 檔案 | 功能 |
| --- | --- |
| `record_alpha.py` | 對 FP2（或傳入通道）濾波與 FFT，找出 α 波所在秒數並寫 DAT。 |
| `record_arousal.py` | 對 FP1／FP2 的第二通道找眼動尖峰，寫入眼動秒數 DAT。 |
| `detect_alpha_and_eyeblink.py` | 一次讀取 EDF 並呼叫前兩個偵測器；目前固定產生 `Alpha.dat`、`eyeblink.dat`。 |

### `eeg_analysis/driving_state/`

| 檔案 | 功能 |
| --- | --- |
| `predict_algorithm.py` | 目前正式的三模式 Tkinter GUI：事件切片、全時程趨勢與駕駛狀態預測；讀取事件 Excel、α DAT、眼動 DAT。此檔仍是修改中版本。 |
| `legacy/sort_event.py` | `predict_algorithm.py` 的舊版：α 累積窗為 1 秒、判定門檻不同；已封存到 `legacy/`，不影響正式流程。 |

### `eeg_analysis/legacy_chinese_gui/`

| 檔案 | 功能 |
| --- | --- |
| `record_status_and_eyeblink_to_xlsx.py` | 從 Status 通道解析 251 → 253 → 254 事件，輸出中文欄位 Excel，並嘗試加入眼動資料。 |
| `main.py` | 讀取中文 Excel 或先從 EDF 轉檔後，產生三圖疊合的舊版 GUI。 |
| `plot_data.py` | `main.py` 的折線圖、長條圖、睡眠區段與圖表疊合函式。 |

### 其他工具

| 位置／檔案 | 功能與狀態 |
| --- | --- |
| `eeg_analysis/eye_movement/eye_movement_validation.py` | 眼動偵測驗證主程式：讀 EDF 與人工 DAT，比對 true／false／miss，輸出自動 DAT、`event_summary.csv`、評估報告與診斷圖。 |
| `eeg_analysis/eye_movement/eye_movement_distribution.py` | 讀取 `eye_movement_validation.py` 輸出的 `event_summary.csv`，繪製 true+miss 與 false 的眼動振幅分布；也會被驗證主程式在 `--distribution` 時直接呼叫。 |
| `tools/fatigue_time_analysis/view_edf_header.py` | 不需額外套件即可檢視 EDF 固定標頭與各通道標頭；用來確認疲勞時間分析所需的 `vehicle position`、`Status` 通道。 |
| `tools/fatigue_time_analysis/analyze_lane_crossing_events.py` | 從 vehicle-position EDF 解析偏移、反應與回復事件，統計偏移時間，並依 100 km/h 資料推估 60 km/h 的疲勞時間標準。 |
| `tools/experiments/check.py` | 比較人工與自動眼動 DAT，會寫 `comparison_details.txt`；輸入路徑目前寫死在其他資料夾。 |
| `tools/experiments/GetAlpha.java` | Java／Android FFT α 波原型，需要 JDSP；沒有對應建置設定。 |

## DAT 命名相容性

DAT 的內容都採「第一個數字為筆數、後續為秒數」格式，但預設檔名仍不一致：

| 產生或讀取處 | DAT 預設名稱 |
| --- | --- |
| `detect_alpha_and_eyeblink.py` | 產生 `Alpha.dat`、`eyeblink.dat`。 |
| `record_status_and_30s_eyeblink.py` | 讀取與 EDF 同資料夾的 `eyeblink.dat`。 |
| `alpha_validation.py` | 讀取人工 `<prefix>_alpha.dat`；眼動為 `<prefix>_raw_arousal info.dat`。 |
| `record_status_and_eyeblink_to_xlsx.py` | 會尋找 `<EDF stem>_raw_arousal info.dat`；對 `*_raw.EDF` 會形成 `*_raw_raw_arousal info.dat`。 |

因此自動偵測的 DAT 不會自動被 FFT／驗證流程找到。後續建議統一為：

```text
<record_id>_alpha_detected.dat
<record_id>_eyeblink_detected.dat
<record_id>_alpha_manual.dat
<record_id>_eyeblink_manual.dat
```

## 執行方式

請在專案根目錄使用模組方式執行，才能正確載入整理後的共用程式：

```powershell
python -m eeg_analysis.feature_extraction.record_status_and_30s_eyeblink --edf data/raw_edf/eeg/s01_061102n_raw.EDF
python -m eeg_analysis.feature_extraction.plot
python -m eeg_analysis.alpha_validation.alpha_validation
python -m eeg_analysis.detection.detect_alpha_and_eyeblink --file data/raw_edf/eeg/s01_061102n_raw.EDF
python -m eeg_analysis.eye_movement.eye_movement_validation --file data/raw_edf/eeg/s01_061102n_raw.EDF --distribution
python -m eeg_analysis.driving_state.predict_algorithm
python -m tools.fatigue_time_analysis.view_edf_header
python -m tools.fatigue_time_analysis.analyze_lane_crossing_events data/raw_edf/auxiliary/s01_060926_1n_car_position.EDF
```
